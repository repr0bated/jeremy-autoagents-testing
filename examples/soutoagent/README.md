# SoutoAgent Example

SoutoAgent is a planning-focused AutoAgents example that coordinates the migration of proxmod-managed dpkg packages to the PackageKit D-Bus backend. It consumes the discovery artifacts generated by `pk-known-start.sh` and exposes the `PackageKitKnowledgeBase` tool so the LLM can resolve package names to canonical PackageKit IDs on demand.

## Prerequisites
- Rust toolchain with `cargo`
- OpenAI API key (or swap the LLM builder to another provider)
- Outputs from `/usr/local/sbin/pk-known-start.sh` (defaults to `/root/pk-known/*.tsv`)

## Usage
```bash
export OPENAI_API_KEY=sk-...
cd AutoAgents
cargo run --package soutoagent -- \
  --task "Draft the proxmod replacement plan for network-manager and its plugins" \
  --pk_map /root/pk-known/pk-known.map.tsv \
  --pk_details /root/pk-known/pk-known.details.tsv
```

Pass a different `--model` flag if you want to target another OpenAI model. The agent enforces batch sizes of ≤25 packages per turn and requires calling the `PackageKitKnowledgeBase` tool whenever it needs canonical IDs or summaries extracted from the `pk-known` snapshots.

### Compare-List Artifact

For CI smoke tests we ship a tiny compare-list under `compare-list.sample.tsv`. It maps a proxmod dpkg name to the canonical PackageKit identifier plus a short summary. Point `--pk_map` / `--pk_details` at this file whenever you are running in a disposable environment that does not have `/root/pk-known/*.tsv` available yet:

```bash
cargo run --package soutoagent -- \
  --pk_map examples/soutoagent/compare-list.sample.tsv \
  --pk_details examples/soutoagent/compare-list.sample.tsv
```

This keeps the autoagent deterministic for automated testing while still exercising the compare-list flow end to end.
